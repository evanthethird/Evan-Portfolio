Interactive Particle System

A Saturn-inspired particle simulation using Three.js, MediaPipe hand tracking, camera input, and fullscreen interaction.

LAUNCH
TRY IT
. . .

🖐️ Hand Controls

Open Hand — Zoom In
Close Hand — Zoom Out
Move Hand Up/Down — Tilt View
Camera Required — Allow access to start

Tools Used

HTML, CSS, JavaScript, Three.js, MediaPipe

Main Skills

3D particles, shaders, camera input, hand tracking, interactive web visuals

Project Type

Interactive web / creative technology project

What the project does

The page renders a particle-based Saturn visual and uses hand tracking to control the animation and interaction.

What it demonstrates

  • Creating a visually rich interactive web project
  • Using camera input and MediaPipe hand landmarks
  • Working with particle systems and animation loops
  • Designing a project that feels impressive as a showcase demo
